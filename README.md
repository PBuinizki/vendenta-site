# Vendenta — Стоматологическая клиника (Ногинск)

Статически генерируемый (SSG) сайт-визитка для стоматологической клиники **Vendenta** (г. Ногинск, Комсомольская ул., 80).

## Стек и архитектура
- **Next.js (App Router, `output: "export"`)** — полная статическая генерация (SSG) главной страницы и страниц направлений через `generateStaticParams`.
- **TypeScript + Tailwind CSS v4** — строгая типизация данных и кастомная красно-белая палитра (Swiss Medical).
- **Framer Motion + Lucide React** — микроанимации, фильтр категорий услуг, адаптивное мобильное меню, модалка онлайн-записи с маской телефона; строго SVG-иконки.
- **Готовность к Headless CMS** — все тексты, услуги, врачи и отзывы изолированы в `src/data/clinic.json` и отдаются через единый слой `src/lib/clinic.ts` (для перехода на Strapi / Sanity / Directus достаточно заменить функции в этом файле).
- **SEO** — `generateMetadata` для каждой страницы, `JSON-LD` (`schema.org/Dentist`), статические `sitemap.xml` и `robots.txt`.

## Локальный запуск и сборка SSG

```bash
# Установка зависимостей
npm install

# Режим разработки
npm run dev

# Сборка статики в папку out/ и локальный просмотр
npm run build
npx serve out
